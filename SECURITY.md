
# Security Policy

## Supported Versions

Cluebench is currently in early development and has no supported releases yet. This section will be updated when releases become available.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report vulnerabilities privately using GitHub's private vulnerability reporting feature:

https://github.com/Cludewn/cluebench/security/advisories/new

When possible, include:

- A description of the vulnerability and its potential impact.
- The affected version or commit.
- Steps to reproduce or a minimal proof of concept.
- Any known mitigations or workarounds.

Do not submit real passwords, credentials, sensitive clues, or confidential project data. Use synthetic test data whenever possible.

## Response and Disclosure

Cluebench is maintained by an individual. Security reports are reviewed on a best-effort basis, and no fixed response or resolution time is guaranteed.

Please allow time for investigation and coordinate public disclosure with the maintainer when possible.
